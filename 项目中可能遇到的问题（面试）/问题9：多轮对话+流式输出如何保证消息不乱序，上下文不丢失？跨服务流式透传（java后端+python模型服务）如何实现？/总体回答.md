后端（Java）层：

关键设计：

- 全局单调递增的EventId ： eventId = Instant.now().toEpochMilli() + "-" + UUID.randomUUID() ，保证唯一性和时序性
- 顺序写入保证 ： BusinessRiskEventStore.append() 使用 synchronized 锁保证线程安全，事件按写入顺序存储
- Deque数据结构 ：每个session维护一个双端队列，保证FIFO顺序

去重策略：

- 使用 Set 记录已处理的eventId，防止重复处理

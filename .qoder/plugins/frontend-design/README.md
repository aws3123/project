# Frontend Design

> Guidance for distinctive, intentional visual design when building new UI or reshaping an existing one.

## Source

- **Author**: Anthropic
- **Repository**: https://github.com/anthropics/claude-code
- **License**: MIT

## What it does

This skill guides creation of distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics. It covers:

- **Design principles** — typography, color, motion, spatial composition
- **Process** — brainstorm, plan, critique, build, critique again
- **Self-critique** — restraint, signature elements, quality floor
- **Writing in design** — copy that serves the user, not the system

## Usage

Once installed, the skill is automatically applied when working on frontend UI tasks. It helps with aesthetic direction, typography choices, and making design decisions that don't read as templated defaults.
